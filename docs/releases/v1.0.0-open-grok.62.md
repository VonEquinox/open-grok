# Open Grok v1.0.0-open-grok.62

This release merges the latest upstream Open Grok 1.0 session, safety, provider,
MCP, and collaboration updates while retaining this fork's provider isolation
and API-key configuration behavior.

## Upstream integration

- Reliable session loading, replay, rewind, queueing, cancellation, and shutdown
  behavior from the upstream 1.0 line.
- Hardened permissions, restore/fetch handling, Git operation gates, MCP
  discovery, search persistence, and large-session performance.
- Meta API support, OpenAI image generation tools, provider reasoning and fast
  routing fixes, and hermetic provider/session tests.
- Team mailboxes now steer live agents, and mid-swarm messages detach a running
  cohort without cancelling its members; `swarm_wait` rejoins it later.

## Open Grok compatibility

- xAI, Codex, Kimi, Fireworks AI, DeepSeek, Meta, Wafer AI, and OpenCode Go
  credentials and catalogs remain isolated.
- Code Mode transport and persistent V8 behavior remain provider-specific.
- The public binary remains `open-grok`; runtime state remains under
  `$OPENGROK_HOME`, `~/.opengrok`, and project `.opengrok/`.

## Install

```sh
curl -fsSL https://github.com/VonEquinox/open-grok/releases/latest/download/install.sh | bash
open-grok --version
```
