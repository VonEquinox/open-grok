# Open Grok v0.1.220-open-grok.48

This release adds Wafer AI as an isolated provider and brings OpenAI Code Mode
web search in line with the latest upstream Codex contract.

## Wafer AI

- **Provider-isolated authentication** — store Wafer API keys in their own
  scope, support `WAFER_API_KEY`, and prevent stored credentials from being
  sent to untrusted custom hosts.
- **Dynamic model discovery** — load the authoritative model catalog from
  Wafer's `/models` endpoint and expose those models through Settings and
  provider login flows.
- **Live session rebinding** — refresh active Wafer sessions after credential
  changes while holding queued prompts until the new route is ready.

## Code Mode web search

- **Upstream search contract** — adopt the latest `web__run` command schema,
  browsing guidance, citation policy, and optional-field behavior.
- **Request parity** — preserve the two visible user turns, apply the upstream
  assistant-context budget, omit empty input, and use the current 10,000-token
  search output policy.
- **Reliable fallback** — retain hosted search when a selected client search
  replacement is unavailable or filtered from the final tool surface.
