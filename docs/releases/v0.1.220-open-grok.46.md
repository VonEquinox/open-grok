# Open Grok v0.1.220-open-grok.46

This release adds Fast mode for Codex models with priority routing and hardens
the DeepSeek Responses dialect.

## Fast mode

- **`/fast` for Codex models** — a session-scoped toggle for models that
  advertise a Fast service tier in the Codex catalog (`service_tiers` or legacy
  `additional_speed_tiers`). Enabling maps to `service_tier=priority` on the
  Responses wire; disabling returns to standard routing.
- **Model-aware gating** — `/fast` only appears when the active model supports
  it, preserves the session's reasoning effort when toggled, and drops the
  selected tier after switching to a model that cannot run it.

## DeepSeek

- **Fail-closed history replay** — the DeepSeek Responses dialect explicitly
  declines opaque provider-native history replay, keeping provider history
  isolated by construction.
- **Coverage and docs** — sampler tests assert DeepSeek accepts both Chat
  Completions and Responses backends (and rejects Messages), and the provider
  table and configuration guide now document V4 Flash's Responses routing.
