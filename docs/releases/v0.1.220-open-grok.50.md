# Open Grok v0.1.220-open-grok.50

This release adds the `ultracode` built-in workflow and teaches blocked
workflow runs to hand their blocker back to the session agent instead of
stopping.

## Workflows

- **`/ultracode <task>`** — new built-in maximum-rigor coding workflow: a
  codebase scout with parallel readers, two competing designs merged by a
  judge, an implementer, and up to four adversarial review lenses over bounded
  fix rounds, delivering a `verified`/`partial`/`needs_attention`/`blocked`
  report.
- **Blocked runs come back** — every script-initiated pause except a
  deliberate user pause now wakes the session agent with the blocking issue
  and exact fix-and-resume instructions, and a failed run re-executes its
  failed step live on resume.
- **`escalate(message)`** — new journaled script gate: the run blocks, the
  agent fixes the cause and resumes with `resume_note`, and the script
  receives the note as the gate's return value with all prior agent work
  replayed from the journal.

## Fixes

- **Pager test drift** — provider-picker and settings tests updated for the
  Wafer AI provider, and the queue-drain tests are hermetic against
  machine-local `[ui]` config by construction, with a guard test.
