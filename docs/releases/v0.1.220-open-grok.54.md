# Open Grok v0.1.220-open-grok.54

This release merges the latest Open Grok updates through upstream
`v0.1.220-open-grok.53` while preserving this fork's API-key-only startup and
OpenAI-compatible Responses handling.

## Runtime and safety

- Protects `.opengrok` permission, sandbox, and managed configuration files
  from silent agent edits.
- Improves per-turn authentication retry budgeting and credential provenance.
- Makes Stop cancel in-flight compaction and improves session resource cleanup.
- Hardens background task waiting, PTY teardown, and configuration watchers.

## Interface

- Adds the optional Enter steering setting for mid-turn sends.
- Expands Advanced feature flags and shows richer descriptions on selection or
  hover.
- Includes dashboard, plan viewer, question navigation, and terminal fixes from
  upstream 0.2.117 through 0.2.119.

## Platform assets

- Windows x86_64 executable and checksum.
- macOS Apple Silicon executable and checksum.
- Ubuntu 20.04-compatible x86_64 archive and checksum, built against glibc 2.31.

The release workflow verifies every artifact, uploads the exact bytes, downloads
them again, and compares them before marking this release as Latest.
