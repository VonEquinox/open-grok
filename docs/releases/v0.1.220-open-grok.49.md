# Open Grok v0.1.220-open-grok.49

This release fixes foreground agent swarms in Code Mode.

## Agent swarms

- **No wait polling loop** — keep `agent_swarm` as a direct top-level tool
  instead of nesting it inside a yielding Code Mode `exec` cell.
- **Foreground completion** — hold the model turn until every swarm member has
  finished and the ordered aggregate result is ready.
- **Consistent provider behavior** — prevent nested swarm duplication across
  Codex, xAI, and DeepSeek Code Mode routes.
