# Open Grok v1.0.0-open-grok.61

This release makes mid-swarm user messages steer the model immediately instead
of waiting for the whole `agent_swarm` cohort to finish.

## Detachable swarm steering

- **Steer without cancelling.** A typed message during an active `agent_swarm`
  (or `swarm_wait`) merges as a mid-turn interjection and fires an orchestration
  steer signal. Members keep running; the turn is not aborted.
- **Detached cohort handoff.** The swarm tool returns a partial
  `<agent_swarm_result state="detached">` and parks the scheduler in
  `SwarmRegistry` so spawn receivers stay alive.
- **`swarm_wait` rejoins.** Call `swarm_wait` later to collect the full XML
  result. A further steer during that wait can detach again.
- **Completion notice.** When a detached swarm finishes mid-turn, the shell
  injects a compact system reminder naming the cohort for `swarm_wait`.
- **Pager marker.** Swarm cards show a `detached ·` header prefix while the
  cohort is still running in the background.

## Open Grok compatibility

- Provider isolation, Code Mode transport, and `$OPENGROK_HOME` state
  boundaries are unchanged. `agent_swarm` and `swarm_wait` remain direct
  top-level tools in Code Mode.

## Install

```sh
curl -fsSL https://github.com/mweinbach/open-grok/releases/latest/download/install.sh | bash
open-grok --version
```
