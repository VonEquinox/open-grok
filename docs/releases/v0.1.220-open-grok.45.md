# Open Grok v0.1.220-open-grok.45

This release adds DeepSeek V4 Flash support, expands Code Mode web search, and
improves subagent orchestration.

## Models and web search

- **DeepSeek V4 Flash** — routes `deepseek-v4-flash` through DeepSeek's
  stateless Responses API with provider-local API-key authentication, reasoning
  effort controls, function tools, and hosted web search. DeepSeek V4 Pro
  remains on Chat Completions.
- **Standalone Code Mode search** — makes Codex standalone web search available
  inside embedded Code Mode while preserving hosted-search fallbacks and
  provider-specific routing.

## Subagents

- **Per-task reasoning effort** — task, swarm, and workflow launches can
  override reasoning effort for the selected child model.
- **Reliable swarm lifecycle** — keeps swarm schedulers authoritative over
  member execution and distinguishes swarm progress from ordinary child tasks.
- **Safer child tool surface** — prevents subagents from receiving unsupported
  plan-mode lifecycle tools after their final harness is built.
