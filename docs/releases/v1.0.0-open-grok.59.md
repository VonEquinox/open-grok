# Open Grok v1.0.0-open-grok.59

This release moves Open Grok onto the upstream Grok Build **1.0.0** line and
ports every published upstream snapshot from `e5478eff` through `8a14c91d`.
Open Grok versions now follow the upstream public version while retaining the
fork release serial (`1.0.0-open-grok.59`).

## Sessions and interface

- **Reliable attach and close** — clients can resume without transcript replay,
  explicitly close sessions, and wait on a load barrier before queued work is
  released.
- **Queue correctness** — rapid send-now, interjection, cancellation, and
  subagent-wait paths preserve queued prompts, slash commands, and images.
- **Session tools** — dashboard turn summaries, disk-usage reporting, usage
  details, improved rewind confirmation, cleaner API errors, and responsive
  markdown tables.
- **Terminal lifecycle** — faster clean exit, bounded shutdown, tmux/SSH theme
  detection, stable selection and CJK copying, and consistent blocking-card
  keyboard handling.

## Runtime, tools, and safety

- **Large-session performance** — session copies stream unbounded update logs
  instead of materializing them, and persisted replay/search are split into
  bounded, testable stages.
- **Permissions and sandboxing** — faster deny-glob matching, clearer script
  prompts, structured security findings, safer restore/fetch handling, and git
  operation gates.
- **Subagents and workflows** — bounded admission queues prevent runaway
  parallel fan-out while Open Grok's task, swarm, workflow, and mailbox
  surfaces remain distinct.
- **MCP reliability** — managed gateway discovery, reconnect reminders,
  disabled-server recovery, tool-image transport, and doctor isolation are
  aligned with upstream v1.

## Open Grok compatibility

- xAI, Codex, Kimi, Fireworks AI, DeepSeek, Meta, Wafer AI, and OpenCode Go
  retain isolated credentials, catalogs, hosted tools, opaque history, and
  export boundaries.
- Code Mode keeps provider-specific transport, persistent V8 execution, hidden
  `exec`/`wait` wrappers, and nested tool rendering.
- Runtime state remains isolated under `$OPENGROK_HOME`, `~/.opengrok`, and
  project `.opengrok/`; the public binary remains `open-grok`.

## Install

```sh
curl -fsSL https://github.com/mweinbach/open-grok/releases/latest/download/install.sh | bash

```
