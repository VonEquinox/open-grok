# Open Grok v0.1.220-open-grok.47

This release completes the latest upstream compatibility pass and fixes the
regressions uncovered during full workspace and PTY validation.

## Models and providers

- **Custom xAI endpoints** — retain the bootstrap model only when a custom
  endpoint returns no usable xAI catalog, while respecting valid remote model
  catalogs and explicit model overrides.
- **Safer model recovery** — repair removed or stale current-model selections
  before implicit sessions begin, avoiding startup failures after catalog
  changes.
- **Provider isolation** — keep authentication and model behavior scoped to the
  selected provider across settings and session tests.

## Runtime reliability

- **Wake and cancellation handling** — close races around automatic wake
  reservations, task cancellation, reminders, and turn completion.
- **Shell and tracing fixes** — preserve Bash `allexport` state correctly and
  record upload timing without carrying stale turn state.
- **Compaction and worktree cleanup** — harden fit calculations and automatic
  worktree garbage collection around boundary conditions.

## Terminal experience

- **Plan approval controls** — restore the documented `a` approval shortcut in
  the plan footer and PTY flows.
- **Settings and notices** — align settings close behavior, privacy banners,
  notices, and tests with the ported upstream interaction model.
- **Hermetic PTY models** — make the PTY harness choose its mock model
  explicitly so end-to-end runs remain deterministic.
