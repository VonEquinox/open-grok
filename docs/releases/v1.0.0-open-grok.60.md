# Open Grok v1.0.0-open-grok.60

This release fixes agent-to-agent messaging so peer messages act instead of
rotting in unread mailboxes, and clarifies the collaboration tool contract.

## Agent collaboration

- **`send_message` now steers.** A message to a running agent is delivered
  live into its turn at an interjection boundary; an idle recipient is woken
  with an agent-message turn. Messages queue only when the recipient cannot
  receive yet (still pending, or the root session is unreachable).
- **Queued steering mail flushes on start.** Mail accepted while a child was
  still pending is delivered to the live session, in FIFO order, the moment
  the child starts — it no longer requires the recipient to poll `wait_agent`.
- **`followup_task` is the passive queue.** It appends to the recipient's
  mailbox without interrupting current work; the recipient drains it with
  `wait_agent` at a stopping point.
- **Clearer tool guidance.** `send_message`, `followup_task`, `wait_agent`,
  and `list_agents` descriptions now state the steering/queue split, that a
  queued message will still be delivered (never resend), and that the roster
  and inbox should not be polled speculatively.

## Open Grok compatibility

- Provider isolation, Code Mode transport, and `$OPENGROK_HOME` state
  boundaries are unchanged.

## Install

```sh
curl -fsSL https://github.com/mweinbach/open-grok/releases/latest/download/install.sh | bash
open-grok --version
```
